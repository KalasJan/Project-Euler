# Project Euler – Algorithmic & Mathematical Challenges

A collection of optimized Python solutions for complex mathematical problems from Project Euler, focusing on number theory, combinatorics, and computational efficiency.

## Key Features
- **Computational Efficiency:** Optimizing code execution to bypass strict timeout limits, focusing on reducing algorithmic complexity.
- **Number Theory Algorithms:** Custom implementations of prime factorization, divisibility checks, modular arithmetic, and Diophantine equations.
- **Combinatorial Logic:** Solving advanced permutation and sequence structures through algebraic formulas rather than raw brute-force iteration.
- **Performance Patterns:** Utilizing dynamic programming, generator expressions, and specialized math module structures.

## Tech Stack
- **Python Standard Library (`math`, `itertools`, `collections`)** – For built-in high-performance combinatorics, numeric functions, and data structures.

*Notes:*
- *Scripts are focused heavily on optimized mathematical logic. File formatting and structure follow pure algorithmic implementation rules.*
- *Note: name 'PE 2.py' means "Project Euler, problem no. 2'*
